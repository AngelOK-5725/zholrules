## 🐓 Известные баги

1. **Баг:** Экзамен завершается досрочно при >8 ошибок, но UI может показать неполные результаты
   - **Фикс:** В `endQuiz(false)` нужно корректно подсчитать `correctCount` по answered вопросам
2. **Баг:** `localStorage` не синхронизируется между вкладками (нужен `storage` event listener)
3. **Баг:** При добавлении медиа в админке нет предпросмотра перед сохранением
4. **Баг:** Тёмная тема не сохраняется при перезагрузке (может сбрасываться до `false`)
