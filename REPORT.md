## 2. Новые фичи

### 2.1 Режим "Карточки" (Flashcards)

**Что:** Новый режим обучения по типу Anki/Quizlet.

**Как работает:**
- Карточка с вопросом по центру экрана
- Варианты ответов внизу
- При неправильном ответе — карточка **переворачивается** (3D-анимация) и показывает пояснение
- **Свайп влево** — отметить "для повторения"
- **Свайп вправо** — следующий вопрос
- Кнопки "Для повторения" и "Далее" под карточкой

**Технические деталы:**
- CSS 3D-трансформации (`transform: rotateY(180deg)`)
- Touch-обработчики для свайпов на мобильных
- Haptic feedback при ответе
- Вопросы для повторения сохраняются в `/api/errors/bulk`
- Анимация появления карточек (`slideInUp`)

**Статус:** ✅ Работает

---

### 2.2 Режим "Состязание" (Online 1v1)

**Что:** Реалтайм-состязание с другим игроком в Telegram.

**Как работает:**
1. Игрок нажимает "⚔️ Состязание"
2. Попадает в очередь matchmaking
3. Когда найден противник — оба получают 10 одинаковых вопросов
4. Отвечают одновременно, счёт обновляется в реальном времени
5. Когда оба закончили — определяется победитель
6. Результат: 🏆 Победа / 😤 Поражение / 🤝 Ничья

**Технические деталы:**
- **Flask-SocketIO** — WebSocket для real-time связи
- **Matchmaking** — очередь в памяти сервера
- **Competition модель** — все матчи сохраняются в БД
- **Синхронизация** — одни и те же вопросы для обоих
- **API:** `/api/competitions`, `/api/competitions/stats`

**Эндпоинты:**
```
GET  /api/competitions      — история матчей
GET  /api/competitions/stats — статистика (победы/поражения)
```

**WebSocket события:**
```
competition_join       — вход в очередь
competition_start      — матч начат
competition_answer     — отправка ответа
competition_result     — результат матча
competition_leave      — выход из очереди
```

**Статус:** ✅ Работает (тестировать в 2 окнах браузера)

### 2.3 No-Code Настройки (Admin Panel)

**Что:** Теперь цены и лимиты можно менять прямо из админки без передеплоя сервера.

**Настройки в БД:**
| Ключ | Значение | Описание |
|------|----------|----------|
| `pro_stars_price` | 1500 | Цена Pro подписки в Stars |
| `free_error_limit` | 10 | Лимит ошибок (бесплатный план) |
| `max_daily_lives` | 3 | Количество жизней в день |
| `daily_questions_target` | 10 | Цель вопросов в день |
| `exam_questions` | 40 | Вопросов в экзамене |
| `exam_time_minutes` | 40 | Время экзамена (мин) |
| `mini_game_duration` | 60 | Длительность мини-игры (сек) |
| `free_plan_enabled` | true | Бесплатный план доступен |
| `pro_plan_enabled` | true | Pro план доступен |
| `lives_stars_price` | 5 | Цена +3 жизней в Stars |

**API:**
```
GET  /api/settings         — все настройки
POST /api/settings         — обновить несколько
PUT  /api/settings/<key>   — обновить одну
```

**UI в админке:**
- Вкладка "⚙️ Настройки" — первая по умолчанию
- Поля ввода для числовых значений
- Тогглы для вкл/выкл
- Кнопка "Сохранить"

**Статус:** ✅ Работает

### 3.1 Система жизней (была полностью сломана)

**Проблема:** Жизни проверялись перед экзаменом, но **никогда не снимались**.

**Исправление:**
- ❌ → ✅ Жизни **тратятся** за неправильный ответ в экзамене (-1 за ошибку)
- ❌ → ✅ Pro пользователи — безлимитные жизни (не тратятся)
- ❌ → ✅ Предупреждение когда осталась 1 жизнь
- ❌ → ✅ Покупка жизней за Telegram Stars (+3 за 5 Stars)
- ❌ → ✅ Webhook обрабатывает оплату жизней

**Flow:**
```
У тебя 3 жизни
→ Начинаешь экзамен
→ Неправильно → 2 жизни
→ Неправильно → 1 жизнь
→ Предупреждение!
→ Неправильно → 0 жизней
→ Экзамен завершается
```
