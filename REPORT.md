## 2. Что сделано за сегодня

### 2.1 Дашборд аналитики (Admin Panel)

Вкладка "📊 Дашборд" в админке показывает:
- Всего пользователей
- Активны сегодня / за неделю
- Pro подписчиков
- Всего ответов + средняя точность
- Количество соревнований
- **Топ-10 пользователей** по количеству ответов

**API:** `GET /api/admin/analytics`

---

### 2.2 Управление пользователями (Admin Panel)

Вкладка "👥 Юзеры" — список всех пользователей с возможностью:
- Посмотреть статистику (ответы, точность, подписка)
- **Назначить Pro** на определённое количество дней
- **Снять Pro**

**API:** `GET /api/admin/users`, `POST /api/admin/user/:id/subscription`

---

### 2.3 Система скидок (No-Code)

В настройках админки доступны:
- Включить/выключить скидку
- Размер скидки (%)
- Цена со скидкой (Stars)
- Дата окончания (YYYY-MM-DD)

Автоматически применяется к Pro подписке. Показывается в карточке подписки.

---

### 2.4 Починена система жизней

**Было:** Жизни никогда не снимались, система не блокировала при 0.

**Стало:**
- **-1 жизнь** за неправильный ответ в экзамене
- **Pro пользователи** — безлимитные жизни
- **Owner** — безлимитный доступ (всё бесплатно)
- При 0 жизней — **блок** → модалка оплаты
- Предупреждение при 1 жизни
- Покупка +3 жизней за Stars

## 4. Модели БД

```
User               — пользователи (tg_id, name, goal, is_admin)
UserStats          — статистика (answered, correct, streak, lives)
UserCategoryStats  — прогресс по категориям
UserError          — ошибки пользователя
Subscription       — подписки (free/pro, expires_at)
Category           — категории вопросов
Question           — вопросы (текст, варианты, пояснение)
Setting            — настройки бизнеса (no-code)
Competition        — матчи 1v1 (player1, player2, scores, winner)
```

## 6. Локальная разработка

```bash
cd zholrules
python run_local.py
# → http://localhost:5000
```

**`run_local.py`:**
- SQLite (не PostgreSQL)
- Telegram авторизация отключена
- Dev-пользователь = админ (OWNER_TELEGRAM_ID=12345678)
- Debug mode
